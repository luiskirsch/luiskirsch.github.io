# Security Policy

## Reportar uma Vulnerabilidade

**Não abra uma issue pública para vulnerabilidades de segurança.**

Envie um e-mail para **luishenriquekirsch@hotmail.com** com:

- Descrição detalhada da vulnerabilidade
- Passos para reproduzir
- Impacto estimado
- Prova de conceito, se disponível

**Confirmação**: 48 horas. **Patch**: de acordo com a severidade (crítico = 24h).

## Escopo

Frontend da plataforma O SextoLugar hospedado em `luiskirsch.github.io` e `preludiojogos.com`.

## Divulgação Responsável

Aguardar 90 dias após o reporte antes de divulgação pública.
